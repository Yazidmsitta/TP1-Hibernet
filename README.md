# TP1 — Catalogue de produits avec Hibernate et H2

Application Java utilisant JPA/Hibernate et une base H2 en mémoire pour enregistrer un catalogue, afficher les produits et rechercher un produit par son identifiant.

## Captures d'écran

### Résultats dans la console H2

La requête `SELECT * FROM PRODUIT;` affiche les trois produits enregistrés dans la base.

![Console H2 : table PRODUIT et résultats de la requête](docs/images/h2-produits.png)

### Exécution dans IntelliJ IDEA

La console affiche le catalogue, le résultat de la recherche du produit d'identifiant 2 et les informations de connexion à H2.
